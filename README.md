## How to run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`. For a local test, point it elsewhere with `OUTPUT_DIR`:

```sh
OUTPUT_DIR=/tmp/test python3 main.py
```

## Winning entry

> Ctrl+Alt+Defeat, a robot band that lost every battle of the bands. Hit single: 'Turn It Off and On Again'.

**106 characters** (under the 200 character limit).

The name is a joke on first read (Ctrl+Alt+Del turned into Defeat), "lost every battle of the bands" is a second beat that only works with that name, and the hit single is the classic tech-support line, a second laugh that fits a band of robots. Six candidate names were compared head to head in `main.py` before this one was picked.
